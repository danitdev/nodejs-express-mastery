# Node.js Backend Development Course

This repository contains my progress and projects while learning backend development with Node.js.

The goal of this course is to understand how to build server-side applications using modern Node.js technologies, including building APIs, working with databases, authentication, sessions, and application architecture.

## 🚀 Technologies Covered

- Node.js
- Express.js
- JavaScript (ES Modules)
- MVC Architecture
- REST APIs
- Middleware
- Routing
- Authentication & Authorization
- Sessions & Cookies
- Sequelize ORM
- MySQL
- Database Relationships
- Template Engines (EJS)
- Error Handling
- Environment Variables
- Security Best Practices
